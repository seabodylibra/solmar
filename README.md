[![rank](https://make.fun/badge/gta6-01/seabodylibra/solmar/rank.svg)](https://make.fun/c/gta6-01)
[![reward](https://make.fun/badge/gta6-01/seabodylibra/solmar/reward.svg)](https://make.fun/c/gta6-01)

Solmar is a sunny seaside open-world crime game built for the [make.fun gta6-01 bounty](https://make.fun/c/gta6-01): a browser game with a drivable city, car theft, traffic, pedestrians, a police wanted system, a five-mission story, combat, a HUD with minimap, and save.

## Play

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. WASD to drive, E to steal a car, Space to handbrake.
